# Quick AI RAG chat web app
Simple RAG chat web app using ChromaDB (vector database) + Gemini Flash 3 LLM

Create a ".env" file in your local project folder and put the following in there:

1) Needed or use alternative AI provider key:
GEMINI_API_KEY = "FREE-API-KEY-HERE"

2) Optional:
Use cohere for embeddings if not using ChromaDB (embedding done for you):
cohere = "FREE_API_KEY_HERE"
